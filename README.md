# Homebody

오프라인 건강 기록 안드로이드 앱. 걸음 · 체중 · 식단 · 운동 · 운동 중 음악을 한 앱에서 기록하고, 데이터는 기기 밖으로 나가지 않음.

## 기능

| 탭 | 내용 |
|---|---|
| 오늘 | 걸음 · 칼로리 수지 · 체중 · 그날 식단 · 운동 요약 |
| 운동 | 러닝 · 걷기 GPS 기록(경로 · 페이스 · 랩 · 음성 안내), 맨몸 운동 세트 · 타이머, 운동 달력 |
| 음악 | 기기 음악 재생 · 재생목록. 운동 화면에서 바로 조작 |
| 식단 | 음식 · 레시피 · 끼니 세트 메뉴로 섭취 기록 |
| 체중 | 체중 기록 · 기간별 추세 |
| 기록 | 기간별 칼로리 수지 · 걸음 · 운동 요약, PDF 저장 · 텍스트 공유 |

- 걸음: 기기 걸음 센서, Health Connect 걸음 읽기 선택
- Health Connect로 체중 · 운동 기록 내보내기 선택
- JSON 백업 · 복원, CSV 내보내기

## 설치

[Releases](../../releases)에서 `Homebody-<버전>.apk`를 받아 설치. Android 11 이상.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 기록 · 설정 유지
- 앱 안 업데이트 알림 없음. Releases 페이지에서 직접 확인
- 서명 인증서 SHA-256: `1a277fae84af21854bee6da6f2aae7fed6bbd4c1022ca9103addd0fca3988b4d`
  (`apksigner verify --print-certs Homebody-<버전>.apk`로 확인)

## 개인정보

- **인터넷 권한 없음.** 수집 · 전송하는 데이터 없음. 계정 · 광고 · 사용 통계 · 오류 보고 없음
- 모든 기록은 기기 안 DB에만 저장. 앱 삭제 시 함께 삭제 (Android 자동 백업도 끔)
- 위치는 러닝 · 걷기 기록 중에만 사용. 지도는 타일 없이 경로선만 그림
- Health Connect 연동은 사용자가 켤 때만. Health Connect도 기기 안 저장소
- 백업 · 보고서 파일은 사용자가 고른 위치에만 저장
